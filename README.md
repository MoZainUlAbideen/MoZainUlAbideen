<div align="center"><h2>👨‍💻 About Me</h2></div>

I'm **Zain**, an **AI Engineer** and Electrical Engineering graduate from **NUST (CEME)**. I take ML and LLM products from prototype to production: retrieval, agents, computer vision and speech, with a deployed backend and a frontend people actually use.

**I build reliable AI systems, measured before they ship.** AI does the work; my job is making sure it's right. Every project below has to pass four rules:

1. **Measured, not assumed.** Held-out test sets and a simple baseline to beat, with a public accuracy page.
2. **A deterministic check around the model.** Quotes, citations and numbers are verified in plain code before anyone sees them.
3. **Failures in the open.** The results that didn't flatter me are documented next to the ones that did.
4. **Gated in CI.** If a change makes a metric worse, the build fails instead of quietly shipping.

What I work on:

- 🔎 **Retrieval & RAG**: hybrid search (BM25, embeddings, character n-grams, RRF, cross-encoder rerankers) with answers that cite the exact source.
- 🎙️ **Speech**: Whisper transcription with word-level timestamps, so answers point to the second something was said.
- 🌿 **Computer vision**: fine-tuned classifiers, segmentation and zero-shot CLIP, optimised with ONNX to run on small servers.
- 🤖 **Agents**: bounded pipelines with routers, critics and repair passes, not open-ended loops.
- 🇵🇰 **AI for Pakistan**: Urdu, Roman Urdu and English interfaces for electricity bills, farming and the law.

> **Open to:** AI Engineer · ML Engineer · Applied AI / LLM Engineer · Forward Deployed Engineer · full-time, on-site or remote

<summary><b>🎙️ Earshot: Ask a Podcast a Question, Hear the Exact Moment It Was Answered</b></summary>

<br/>

Transcribes podcast episodes, searches them with keyword and meaning search together, writes a short answer, and links every quote to the second it was said. Clicking a citation plays the original audio from that moment.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, FastAPI, Whisper large-v3-turbo, PostgreSQL full-text search, pgvector, bge-small, jina-reranker, Groq (gpt-oss-120b), Next.js, Render, Vercel |
| **Pipeline** | Audio → Whisper with word timestamps → 875 overlapping passages → hybrid search (RRF) → cross-encoder rerank → LLM answer → verbatim quote checker → one repair pass |
| **Evaluation** | Each stage measured separately: transcription on LibriSpeech, search on 45 paraphrased questions, full answers end to end |
| **Results** | **2.65% WER** · recall@5 **0.76 → 0.93** with the reranker · answered **77.8% → 93.3%** with the repair pass · every quote shown matches the transcript word for word |
| **Engineering** | Postgres job queue with leases and fencing tokens · per-IP rate limits and a daily token budget · CI against a real pgvector database |
| **Trade-off** | The free server has a tenth of a CPU, where the reranker takes 1.35 s vs 69 ms, so the live site runs hybrid search and says so |
| **Live** | [earshot-ten-pi.vercel.app](https://earshot-ten-pi.vercel.app/) |
| **Repository** | [Earshot](https://github.com/MoZainUlAbideen/Earshot) |

</details>

<summary><b>🌾 Dehqan (دہقان): A Crop Doctor That Tells You When It Isn't Sure</b></summary>

<br/>

Looks at a photo of a sick leaf, names the likely condition, grades how bad it is, and finds safe hours to spray from a live forecast. When it isn't confident, it says so and sends the farmer to the local agriculture extension office instead of guessing. English and Urdu throughout.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, PyTorch, MobileNetV3, CLIP, LR-ASPP segmentation, ONNX Runtime, FastAPI, Next.js, Render, Vercel |
| **Models** | 27-condition, 13-crop leaf classifier · zero-shot CLIP "is this a leaf?" gate · segmentation-based severity grader · keyword router for English, Roman Urdu and Urdu |
| **The honest finding** | A lab-trained model scores **95.5%** on lab photos but **11.5%** on real field photos. Adding ~1,800 field photos lifts it to **47.4%** (baseline 7.4%), still not good enough to rely on |
| **Results** | Answers **24%** of field photos at **79%** accuracy (0.9 confidence) · CLIP gate accepts **99.8%** of leaves vs **23.6%** using classifier confidence · severity grade **81.5%** vs 42% baseline · refused **7/7** pesticide-dose questions |
| **Engineering** | PyTorch → ONNX with int8 CLIP: server memory **909 → 220 MB** to fit a 512 MB host, outputs parity-checked on 1,000 photos |
| **Live** | [dehqan.vercel.app](https://dehqan.vercel.app/) |
| **Repository** | [Dehqan](https://github.com/MoZainUlAbideen/Dehqan) |

Next up: Pakistani field photos for wheat and cotton, the crops that matter most here.

</details>

<br/>

An Urdu-first assistant that reads photos of Pakistani electricity bills, re-checks every charge, explains the bill in plain language, and answers NEPRA regulation questions with the exact clause and page. The LLM writes words; it never does the arithmetic.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, FastAPI, Gemini (vision), Groq (gpt-oss-120b), Docker, Render, Next.js, Vercel, Langfuse, GitHub Actions |
| **Pipeline** | Photo → Gemini reads fields → deterministic audit engine re-checks every figure → targeted re-read on failure → Urdu/English summary · Questions → rule-based router → BM25 + character n-grams (RRF) over 566 clauses → citation critic |
| **Results** | **96.2%** field accuracy on real photos · **0** invented numbers reached users · **91%** held-out English top-5 retrieval · Urdu **0% → 83%** with query rewriting · **6/6** out-of-scope questions refused |
| **Engineering** | 319 tests and 20 eval metrics gated in CI · 2,000 synthetic bills with planted errors (100% caught, 0 false alarms) · Langfuse tracing with PII masking · a weekly watcher for NEPRA document changes |
| **Live** | [rehnuma-kappa.vercel.app](https://rehnuma-kappa.vercel.app) |
| **Repository** | [rehnuma](https://github.com/MoZainUlAbideen/rehnuma) |

Shaped by my neighbours: solar and non-solar households in Peshawar tested the Urdu summaries.
