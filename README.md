<div align="center"><h2>👨‍💻 About Me</h2></div>

I'm **Zain**, an **AI Engineer** and Electrical Engineering graduate from **NUST (CEME)**. I build AI products end to end: data and retrieval, models and agents, evaluation, a deployed backend and a frontend people can actually use.

The rule I build by: **an AI system hasn't worked until I've measured it.** Every project below is live, has a public accuracy page, compares itself against a simple baseline, and reports its failures next to its wins.

- 🔎 **Retrieval & RAG**: hybrid search (BM25, embeddings, character n-grams, RRF, rerankers) with answers that cite the exact source.
- 🎙️ **Speech**: Whisper transcription with word-level timestamps, so answers can point to the second something was said.
- 🌿 **Computer Vision**: image classifiers, segmentation and zero-shot CLIP checks, with models that say "I'm not sure" instead of guessing.
- 📏 **Evaluation-first engineering**: held-out test sets, recall@k and MRR, LLM-as-judge grading, eval metrics gated in CI.
- 🇵🇰 **AI for Pakistan**: Urdu, Roman Urdu and English interfaces for electricity bills and farming.

> **Open to:** AI Engineer • ML Engineer • LLM / Applied AI Engineer • Full-time, on-site or remote

<details open>
<summary><b>🎙️ Earshot: Ask a Podcast a Question, Hear the Exact Moment It Was Answered</b></summary>

<br/>

Transcribes podcast episodes, searches them with keyword and meaning search together, writes a short answer, and links every quote to the second it was said. Clicking a citation plays the original audio from that moment.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, Whisper large-v3-turbo, PostgreSQL full-text search, pgvector, bge-small, reranker, Vercel |
| **Pipeline** | Audio → Whisper with word timestamps → 875 passages indexed → hybrid search → LLM answer → verbatim quote checker → one repair pass |
| **Evaluation** | Each stage measured separately: transcription on LibriSpeech, search on 45 paraphrased questions, full answers end to end |
| **Results** | **2.65% WER** · recall@5 **0.76 → 0.93** with a reranker · answered **77.8% → 93.3%** with the repair pass · **100%** of shown quotes match the transcript word for word |
| **Trade-off** | The free server has a tenth of a CPU, where the reranker takes 1.35 s vs 69 ms, so the live site runs hybrid search and says so |
| **Live** | [earshot-ten-pi.vercel.app](https://earshot-ten-pi.vercel.app/) |
| **Repository** | [Earshot](https://github.com/MoZainUlAbideen/Earshot) |

</details>

<details open>
<summary><b>🌾 Dehqan (دہقان): A Crop Doctor That Tells You When It Isn't Sure</b></summary>

<br/>

Looks at a photo of a sick leaf, names the likely condition, grades how bad it is, and finds safe hours to spray from a live 5-day forecast. When it isn't confident, it says so and sends the farmer to the local agriculture extension office instead of guessing. English and Urdu throughout.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, PyTorch, CLIP, segmentation model, live weather API, Vercel |
| **Models** | 27-condition, 14-crop leaf classifier · zero-shot CLIP "is this a leaf?" gate · segmentation-based severity grader · keyword router for English, Roman Urdu and Urdu |
| **The honest finding** | A lab-trained model scores **95.5%** on lab photos but **11.5%** on real field photos. Adding ~1,800 field photos lifts it to **47.4%** (baseline 7.4%), still not good enough to rely on |
| **Results** | Answers **24%** of field photos at **79%** accuracy (0.9 confidence) · CLIP gate accepts **99.8%** of leaves vs **23.6%** using classifier confidence · severity grade **81.5%** vs 42% baseline · refused **7/7** pesticide-dose questions |
| **Live** | [dehqan.vercel.app](https://dehqan.vercel.app/) |

Next up: Pakistani field photos for wheat and cotton, the crops that matter most here, and Urdu, Pashto and Punjabi voice notes.

</details>

<details>
<summary><b>⚡ Rehnuma (رہنما): Electricity Bill Audit & Power Guide for Pakistan</b></summary>

<br/>

An Urdu-first assistant that reads photos of Pakistani electricity bills, re-checks every charge, explains the bill in plain language, and answers NEPRA regulation questions with the exact clause and page. The LLM writes words; it never does the arithmetic.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, FastAPI, Gemini (vision), Groq (gpt-oss-120b), Docker, Render, Next.js, Vercel, Langfuse, GitHub Actions |
| **Pipeline** | Photo → Gemini reads fields → deterministic audit engine re-checks every figure → targeted re-read on failure → Urdu/English summary · Questions → rule-based router → BM25 + character n-grams (RRF) over 566 clauses → citation critic |
| **Results** | **96.2%** field accuracy on real photos · **0** invented numbers reached users · **91%** held-out English top-5 retrieval · Urdu **0% → 83%** with query rewriting · **6/6** out-of-scope questions refused |
| **Engineering** | 319 tests and 20 eval metrics gated in CI, Langfuse tracing with PII masking, a weekly watcher for NEPRA document changes |
| **Live** | [rehnuma-kappa.vercel.app](https://rehnuma-kappa.vercel.app) |
| **Repository** | [rehnuma](https://github.com/MoZainUlAbideen/rehnuma) |

Shaped by my neighbours: solar and non-solar households in Peshawar tested the Urdu summaries.

</details>

<details>
<summary><b>♿ Parity: AI Web Accessibility (WCAG 2.2) Auditor</b></summary>

<br/>

Opens a page in a real browser on desktop and mobile, checks whether people with disabilities can use it, explains each problem against the WCAG rule it breaks, and suggests a fix.

| Attribute | Detail |
| :--- | :--- |
| **Stack** | Python, FastAPI, Playwright, axe-core, Gemini (vision), Groq, Docker, Render, Vercel |
| **Pipeline** | Headless Chromium → axe-core rules → pixel-based contrast meter → keyboard-navigation agent → vision agent for alt text → WCAG assistant over 1,092 W3C passages |
| **Results** | Recall on 24 labelled issues **54% (rules alone) → 24/24** with zero false alarms · vision-agent precision **80% → 100%** · settled 66 + 11 of 86 contrast cases rules left undecided |
| **Engineering** | Job queue, rate limits and SSRF protection · 190+ tests with recorded model answers replayed in CI · the site passes its own audit |
| **Live** | [parity-iota-puce.vercel.app](https://parity-iota-puce.vercel.app) |
| **Repository** | [Parity](https://github.com/MoZainUlAbideen/Parity) |
